THE FRAMEWORK (the pieces claimed to be unified)

A regulator scalarizes a hidden value vector via a measured **proxy vector**
P with weights w; agents face **selection pressure** on the scalar index Σ w_j P_j;
hidden harm accrues in the **unmeasured directions**. The component results:
1. **Least-cost gaming / equimarginal load** (agent closes a score deficit at min
   cost; load ∝ κ_j w_j).
2. **Distortion / congruity:** hidden harm is a weighted average of "exchange
   rates" h_j/w_j; zero distortion iff h_j = c·w_j (proportionality).
3. **Set-monotonicity:** adding/removing a measured channel moves harm either way;
   channel *count* is not the governing variable.
4. **Sufficiency:** when is the scalar Σ w_j P_j a sufficient statistic for the
   vector P? (lossless aggregation condition).
5. **Second best / corrective policy:** perfecting one measured margin while
   another stays unmeasured can reduce welfare; corrective policy on a proxy gets
   gamed (a named "Goodhart's law" in economics).
6. **Selection pressure → harm magnitude:** stronger competition/selection on the
   proxy intensifies distortion.
