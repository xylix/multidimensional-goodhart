# Review iteration: response-kernel boundary

Iteration type: `review`

## Review target

Target texts:

- `research/threads/response_kernel_boundary.md`.
- `research/formalization.md`, especially the Iteration 11 type/kernel definition.
- `research/claim_audits.md`.
- `research/red_flags.md` and `research/negative_results.md`.

Core concern: Iteration 11 repaired the too-brittle absolute-continuity boundary by classifying response channels through a declared type space `U`, participation weights `W_theta(u)`, and fixed-type response kernels `K_theta(ds | u)`. This review checks whether the repair really adds usable structure or just moves all ambiguity into the choice of `U`.

## Claim 1: pure selection changes only `W_theta`

- Claim I might use: Pure selection reweights fixed type-conditional behavior.
- What the text actually shows: After declaring `U`, `nu`, and `K_0(ds | u)`, a pure selection channel has `K_theta = K_0` and policy dependence only through `W_theta`. The joint law on `(u, s)` is then a reweighting of the baseline joint law.
- Evidence type: Direct calculation from the joint law `m_0(du, ds) = nu(du) K_0(ds | u)`.
- Main inferential gap: The claim only has content after `U` names the attributes treated as fixed. It is not a fact about `mu_theta` alone.
- Counterexamples and model-breakers:
  1. If `U` includes each agent's full policy-contingent response plan, then many behavior changes can be redescribed as selection over plan-types.
  2. If `U` omits an important stable heterogeneity variable, changing mixtures over that hidden variable can look like a kernel change.
  3. The same marginal law on `S` can be generated by reweighting types or by changing conditional behavior.
- Generalization boundary: The licensed statement is relative: conditional on a declared causal type/action representation, pure selection is exactly reweighting fixed type-conditional behavior.
- Action: keep the definition, but require applications to state why the chosen `U` is substantively fixed rather than an ex post encoding of future responses.

## Claim 2: intervention means `K_theta` changes at fixed type

- Claim I might use: Intervention changes fixed-type behavior.
- What the text actually shows: If `K_theta(ds | u) != K_0(ds | u)` on a positive-`nu` set, then the policy changes the conditional state-generating mechanism for the same modeled type.
- Evidence type: Causal modeling distinction, not an observational identification theorem.
- Main inferential gap: A kernel change is not automatically welfare harm. It is a response-classification fact.
- Counterexamples and model-breakers:
  1. Proxy-only manipulation can change `P` while leaving hidden welfare `H` fixed.
  2. Corrective effort can change behavior in a goal-aligned direction.
  3. A submanifold-limited kernel change may be severe for proxy validity but bounded for hidden harm if the feasible action set does not move `H`.
- Generalization boundary: Kernel change licenses intervention analysis through action sets, costs, constraints, and incentives. It does not license "hidden harm increased" without a harm model.
- Action: separate "intervention" from "damage" in draft prose and examples.

## Claim 3: the boundary is identifiable from induced distributions

- Claim I might use: Observing `mu_theta` across policies tells us whether the channel is selection or intervention.
- What the text actually shows: The induced law is

`mu_theta(A) =
  integral W_theta(u) K_theta(A | u) nu(du) /
  integral W_theta(u) nu(du)`.

This expression visibly confounds `W_theta` and `K_theta` after integrating out `u`.
- Evidence type: Non-identifiability by decomposition.
- Concrete test case: Let `U = {0, 1}` and `S = {0, 1}` with `nu(0) = nu(1) = 1/2`.
  - Decomposition A, pure selection: `K_0(S = 1 | u) = u`; choose weights `W_theta(1) = q/(1 - q)` and `W_theta(0) = 1` to produce any target `Pr_theta(S = 1) = q` in `(0, 1)`.
  - Decomposition B, intervention: keep `W_theta = 1` but set `K_theta(S = 1 | u) = q` for both types.
  - The same marginal `mu_theta` is produced, but the causal stories differ.
- Generalization boundary: Marginal distributions alone can refute some pure-selection stories, for example when support is impossible under the declared joint baseline. They cannot generally identify the unique decomposition into type reweighting and fixed-type response.
- Action: add "not identifiable from distributions alone" as a dead stronger claim, not merely a caveat.

## Claim 4: the test cases classify correctly

### Participation-only response

Types are stable applicant or school attributes. The policy changes participation by `W_theta(u)`, but conditional files or practices are drawn from the same `K_0(ds | u)`.

Verdict: pure selection relative to the declared `U`. This is the case where baseline reweighting bounds belong.

### Epsilon-baseline gaming

Baseline already assigns small probability `epsilon > 0` to gaming-like behavior. Under the metric, the probability rises to `p_theta(u) > epsilon` at fixed type.

Verdict: intervention. Absolute continuity survives on the finite observed state space, but `K_theta` changed.

### Proxy-only manipulation

Agents reformat or optimize a proxy-facing feature while hidden welfare is unchanged.

Verdict: intervention for proxy validity, not necessarily hidden harm. The response-kernel boundary should not smuggle in a welfare conclusion.

### Representation-change example

If `U` is expanded to include the whole response function `theta -> s_theta`, then `K_theta` can be constant and policy effects appear as selection over response-plan types. If `U` collapses heterogeneous stable attributes, changing mixture weights can look like kernel movement.

Verdict: classification requires a pre-declared causal type/action representation. The choice of `U` is part of the model, not a harmless notation.

## Repaired license

The response-kernel boundary survives, but with a narrower and more useful license:

- Pure selection reweights fixed type-conditional behavior.
- Intervention changes fixed-type behavior.
- Both statements are relative to a declared causal type/action representation.
- Applications must say what evidence distinguishes reweighting from fixed-type response: repeated observations of the same type, randomized policy exposure, action traces, structural constraints, or a defensible causal model.
- Observed marginal laws `mu_theta` alone are insufficient in general.
- Kernel change does not imply hidden harm; harm requires a separate hidden-value or welfare model.

## Verdict

Iteration 11's repair is useful and should stay. It marks where the selection bound applies and where intervention analysis needs action/cost geometry. But the boundary is not intrinsic, not representation-free, and not identifiable from marginal distributions alone. The project should present it as a modeling discipline: declare `U`, declare which variables are fixed type versus action, and state what observations would distinguish selection from fixed-type response.
