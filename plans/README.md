# Plans

This directory tracks research and writing plans by lifecycle:

- `plans/*.md` contains active or current plans that are available to execute
  next.
- `plans/could-do/*.md` contains future, optional, or parked ideas that should
  not be treated as the current workstream.
- `plans/archived/*.md` contains completed plans kept for audit trail and
  handoff context.

When a plan is completed, move it from the root of `plans/` to
`plans/archived/` rather than leaving it next to active plans. Historical
research-log references can keep the path that existed when the work happened.
