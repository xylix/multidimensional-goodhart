# Title and Subtitle Exploration

Status: parked exploration. This is not manuscript prose.

## Starting Point

Current working title:

> Multidimensional Goodhart

Current working subtitle:

> Response Channels, Scorecards, and Residual Shape

Concern: the title is already terminological. The subtitle should sell what the
book does for a possible reader, not just list internal framework terms. Core
readers can be assumed to know Goodhart's law in general, but should not be
assumed to know any particular mathematical formalization.

## Desired Direction

The subtitle should be reader-facing and slightly recursive if possible:

- evaluating when Goodhart claims themselves are warranted
- turning Goodhart warnings into measurable or auditable claims
- demystifying Goodhart without implying a universal scalar effect size
- keeping some amusement in the phrasing without making the project sound cute

Prompts that motivated this pass:

- "measuring Goodhart claims' validity"
- "shining light on Goodhart claims"
- "de-mystifying Goodhart"
- "measuring the Goodhart effect size"

## Candidate Families

### Formal / Research-Facing

- *A Framework for Auditing Goodhart Claims*
- *When Goodhart Claims Are Valid*
- *Goodharting Goodhart Claims*

Notes: "Auditing" is probably the best word in this family. It is practical,
recursive, and avoids implying that validity is a single number.

### Explanatory / Broadly Technical

- *Modeling What Changes When Measures Become Targets*
- *From Proxy Pressure to Licensed Calculations*
- *A Framework for Licensing Goodhart Claims*

Notes: these are clear, but less amusing. "Licensed calculations" is accurate
to the book's internal vocabulary, though somewhat insider-facing.

### Measuring / Demystifying

- *From Goodhart Warnings to Measurable Claims*
- *Auditing the Goodhart Effect*
- *When Goodhart Effects Can Be Measured*

Notes: this family best captures the recursive "measure Goodhart" idea while
preserving the book's caution that measurement is conditional on declared
primitives.

## Current Strongest Candidates

- *Multidimensional Goodhart: From Goodhart Warnings to Measurable Claims*
- *Multidimensional Goodhart: A Framework for Auditing Goodhart Claims*
- *Multidimensional Goodhart: When Goodhart Effects Can Be Measured*

## Main Caution

Avoid implying that the book estimates one universal "Goodhart effect size."
The manuscript's core claim is that such measurement is only licensed after
declaring the response channel, hidden value or harm, aggregation, action
geometry, and evidence standard.
